# ITPP - Interactive Pokémon Trainer App
Welcome to ITPP, an Android app that brings the fascinating world of Pokémon to life! With ITPP, you can easily access detailed Pokémon information like stats, abilities, evolution chains, and even listen to their cries. Explore and discover more about your favorite Pokémon in a simple and user-friendly interface.

## Features
View detailed Pokémon data (ID, name, height, weight, stats, types).
- Listen to Pokémon cries.
- Explore abilities and evolution chains for each Pokémon.
- Beautifully designed, simple, and easy-to-use interface.

## Technologies Used
- Android: Native Android development using Kotlin.
- PokéAPI: Fetches data from the PokéAPI for Pokémon information.
- Gson: Used for parsing JSON data from the API.
- Material Design: UI components for building a clean and modern user interface.
- Python: Scripting to retrieve data

## Setup & Installation
### Prerequisites
Make sure you have the following tools installed:

- Android Studio
- Kotlin
- A physical device or emulator for running the app.

### Steps to Set Up
1. Clone the repository:
`git clone https://github.com/sacredpoom/ITPP.git`
`cd ITPP`

2. Open the project in Android Studio:
- Open Android Studio, and choose Open an existing project.
- Navigate to the ITPP folder and open it.

3. Run the app:
- In Android Studio, select your emulator or device.
- Press the Run button to build and run the app.

### Local Changes
- Modify the pokemon_data.json file to change Pokémon data or update it.
- You can also edit the UI in the res/layout folder for further customization.

## Features to Explore
- Pokémon Details: View data such as base stats, abilities, and types.
- Evolution Data: Check out the evolution chain for each Pokémon, including previous and next evolutions.
